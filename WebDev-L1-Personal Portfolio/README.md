## 📖 Project Overview

A clean, modern, and fully responsive **Personal Portfolio Website** designed to showcase technical skills, professional work experience, academic background, featured projects, certifications, and contact channels.

Developed with semantic HTML5 and customized Vanilla CSS3, featuring a contemporary dark-accent aesthetic, smooth scrolling navigation, interactive cards, and responsive layouts across all device viewports.

---

## 🌟 Key Sections

- **Header & Navigation**: Fixed responsive navbar with smooth anchor navigation links to each page section.
- **Hero Section**: Personal introduction, professional role ("Angular Developer"), quick contact chips, and call-to-action buttons.
- **About Me**: Professional summary, key roles, MCA degree summary, and current company background.
- **Work Experience Timeline**: Structured career timeline highlighting roles at *Coderthemes Design* (Angular Developer) and *Bitrix Infotech* (Node.js Developer Intern).
- **Technical Skills**: Categorized skills breakdown:
  - *Frontend*: Angular, TypeScript, HTML5, CSS3, Bootstrap, Tailwind CSS
  - *Angular Core*: Angular Routing, Reactive Forms, Reusable & Standalone Components
  - *Backend & Database*: Node.js, Express.js, EJS, MongoDB, AJAX, jQuery
  - *Dev Tools*: Git, GitHub, VS Code, NPM, Yarn, Bun
- **Education**: Detailed academic achievements (MCA - 8.39 CGPA, BCA - 7.54 CGPA).
- **Featured Projects**: Highlights of real-world applications including *SalonSync* (salon service booking web app) and *Admin Dashboards & Templates Suite*.
- **Certifications**: Verified credential card for *Applied Cloud Computing for Software Development*.
- **Contact Channels**: Interactive contact cards for Email, LinkedIn, GitHub, and Location.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SunitaMaurya2051999/photovoltaic.git
   ```

2. **Navigate to the Portfolio folder**:
   ```bash
   cd "OIBSIP/WebDev-L1-Personal Portfolio"
   ```

3. **Open the project**:
   - Double click `index.html` to launch in your browser.
   - *OR* use VS Code's **Live Server** extension.
