A complete multi-page botanical skincare brand website designed with rich aesthetics and responsive layouts:
- **`index.html`** — Homepage featuring a hero section, organic badges, core value propositions, bestseller preview grid, and newsletter subscription.

- **`contact.html`** — Interactive contact form, studio location, operating hours, and FAQ accordions.

### 🌡️ Task 3: Temperature Converter (`WebDev-L1-Temperature Converter Website`)
A functional, user-friendly temperature converter built with vanilla JavaScript:
- Supports conversion across **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)**.
- **Simultaneous Result Mode**: Converts and displays all units simultaneously in responsive cards.
- **Scientific Validation**: Prevents values below absolute zero ($-273.15\ ^\circ\text{C}$, $-459.67\ ^\circ\text{F}$, $0\text{ K}$) and validates non-numeric inputs.
- Clean glassmorphic design and accessible feedback alerts.
- 🔗 **Detailed Docs:** [Temperature Converter README](./WebDev-L1-Temperature%20Converter%20Website/README.md)

## 💻 How to Run Locally

You can run any of the projects directly in your browser without installing node modules or starting build servers:

1. **Clone this repository**:
   ```bash
   git clone https://github.com/SunitaMaurya2051999/photovoltaic.git
   cd photovoltaic
   ```

2. **Open any project**:
   - For **Landing Page**: Open `WebDev-L1-LandingPage/index.html`
   - For **Personal Portfolio**: Open `WebDev-L1-Personal Portfolio/index.html`
   - For **Temperature Converter**: Open `WebDev-L1-Temperature Converter Website/index.html`

*(Tip: In VS Code, you can right-click any `index.html` and choose **"Open with Live Server"**).*
