# 🌿 GlowSpace — Organic & Botanical Skincare Landing Page
### Oasis Infobyte Web Development & Designing Internship (OIBSIP)
**Track:** Web Development | **Level:** 1 | **Task:** 1 (Landing Page)

---

## 📖 Project Overview

**GlowSpace** is a multi-page, responsive, and modern skincare brand landing page crafted with clean HTML5 and Vanilla CSS3. The project delivers a warm, aesthetic, and trustworthy shopping experience featuring natural botanical beauty products.

It incorporates modern web design principles including harmonious natural color schemes (soft beige, sage green, and warm terracotta), fluid typography using Google Fonts (Poppins), card hover elevations, and responsive layouts across desktops, tablets, and smartphones.

---

## 🌟 Key Features

- **Multi-Page Experience**: Includes 5 dedicated, linked pages for a complete brand showcase:
  - `index.html` — Hero section with CTA, brand value highlights, bestseller preview, and newsletter subscription.
  - `about.html` — Brand heritage, philosophy, clean beauty promises, and core ingredient spotlight.
  - `products.html` — Full product catalog with pricing, category tags, badges, and detailed descriptions.
  - `reviews.html` — Verified customer reviews, 5-star rating breakdowns, and real user feedback.
  - `contact.html` — Interactive contact form, business hours, studio address, and customer care FAQs.
- **Responsive Layout**: Designed mobile-first and fully optimized for mobile devices, tablets, laptops, and ultra-wide screens.
- **Rich Visual Aesthetics**:
  - Curated natural botanical color palette.
  - Smooth micro-interactions, badge highlights, and button hover states.
  - High-quality curated Unsplash imagery for realistic product presentation.
- **Clean & Semantic HTML5**: Accessible structure using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` elements.
- **Pure Vanilla CSS**: Modular, zero-framework, clean stylesheet utilizing CSS custom properties (variables), Flexbox, and CSS Grid.

## 🚀 How to Run Locally

No build tools, bundlers, or servers required!

1. **Clone the repository** (or download the ZIP file):
   ```bash
   git clone https://github.com/SunitaMaurya2051999/photovoltaic.git
   ```

2. **Navigate to the Landing Page folder**:
   ```bash
   cd "OIBSIP/WebDev-L1-LandingPage"
   ```

3. **Open the project**:
   - Double-click on `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave, Safari).
   - *OR* use VS Code's **Live Server** extension by right-clicking `index.html` and selecting **"Open with Live Server"**.

## 📑 Pages Breakdown

### 1. Home Page (`index.html`)
- **Hero Section**: Catchy tagline ("Healthy Skin Starts with Simple Care"), organic badge, dual CTA buttons ("Explore Products", "Our Story").
- **Brand Highlights**: 3 feature cards detailing natural botanical extracts, 100% cruelty-free commitment, and dermatologist-tested safety.
- **Featured Bestsellers**: Preview grid of top skincare products with prices and tags.
- **Newsletter**: High-conversion email subscription call-to-action.

### 2. About Page (`about.html`)
- **Brand Story**: Origin and philosophy of GlowSpace.
- **Four Core Pillars**: Clean formulas, ethical sourcing, eco-friendly packaging, and transparent ingredient lists.
- **Key Botanicals**: Highlights of active natural ingredients like Hyaluronic Acid, Niacinamide, and Green Tea extract.

### 3. Products Page (`products.html`)
- **Catalog Grid**: Complete collection including serums, cleansers, creams, toners, and facial oils.
- **Card Details**: High-res product images, category tags, ratings, prices, and quick purchase buttons.

### 4. Reviews Page (`reviews.html`)
- **Rating Summary**: Overall score (4.9 / 5.0) and visual percentage bars.
- **Customer Cards**: Testimonials with buyer verification badges, ratings, and feedback comments.

### 5. Contact Page (`contact.html`)
- **Contact Form**: Interactive inputs for Name, Email, Subject, and Message.
- **Direct Info**: Email address, studio location, and customer support operating hours.
- **FAQ Section**: Quick answers to shipping, return policies, and cruelty-free certifications.
